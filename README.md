# 👤 Face Distance Detector 
*Detecção de rostos e cálculo de proximidade relativa usando FaceAPI.js*

[![FaceAPI.js Version](https://img.shields.io/badge/faceapi.js-0.22.2-blue)](https://github.com/justadudewhohacks/face-api.js)
[![Open in Visual Studio Code](https://img.shields.io/badge/Open%20in-VSCode-007ACC?logo=visual-studio-code)](https://open.vscode.dev/seu-usuario/face-distance-detector)

“Atualizado após envio do teste para corrigir falhas na exibição da detecção facial.”

## 📌 Funcionalidades
- Carregamento de imagens locais ou remotas
- Detecção de múltiplos rostos usando IA
- Cálculo de distância relativa entre rostos
- Exibição de dados técnicos no console
- Interface visual com marcações interativas

## 🚀 Começando

### Pré-requisitos
- Navegador moderno (Chrome/Firefox/Edge)
- Conexão com internet (para carregar modelos)
- Servidor local (ou extensão Live Server)

### Instalação
```bash
git clone https://github.com/seu-usuario/face-distance-detector.git
cd face-distance-detector

### Como executar:

	MÉTODO 1:
-  Caso já tenha o Visual Code instalado, instale a extensão Live Server
-  Clique com o botão direito em <detector.html> "Open with Live Server"

	MÉTODO 2:
- Instale o python em qualquer versão, recomendada a mais recente
- Abra o terminal diretamente na pasta onde tenha guardado o projeto
- No terminal, escreva "python -m http.server 8000" ou então "python3 -m http.server 8000"
- Em seguida acesse em seu navegador de preferência: "http://localhost:8000/detector.html"
